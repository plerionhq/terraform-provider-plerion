# plerion_aws_integration (Resource)

An AWS account connected to Plerion. Plerion assumes `role_arn` with the tenant's external id before it saves anything, so the role must exist and trust Plerion first. Plerion only assumes a role tagged `RolePurpose = PlerionAccess`.

## Example usage

```terraform
variable "plerion_account_id" {
  description = "Plerion AWS account shown in the Plerion console during onboarding"
  type        = string
}

data "plerion_tenant" "this" {}

resource "aws_iam_role" "plerion" {
  name = "PlerionAccessRole"
  assume_role_policy = jsonencode({
    Version = "2012-10-17"
    Statement = [{
      Effect    = "Allow"
      Principal = { AWS = "arn:aws:iam::${var.plerion_account_id}:root" }
      Action    = "sts:AssumeRole"
      Condition = { StringEquals = { "sts:ExternalId" = data.plerion_tenant.this.external_id } }
    }]
  })

  # Plerion only assumes roles with this tag.
  tags = { RolePurpose = "PlerionAccess" }
}

resource "aws_iam_role_policy_attachment" "security_audit" {
  role       = aws_iam_role.plerion.name
  policy_arn = "arn:aws:iam::aws:policy/SecurityAudit"
}

resource "plerion_aws_integration" "this" {
  role_arn = aws_iam_role.plerion.arn
  name     = "production"

  depends_on = [aws_iam_role_policy_attachment.security_audit]
}
```

## Approval

Plerion holds an account from an AWS organization your tenant hasn't connected before until someone approves it in the Plerion console. `terraform apply` doesn't wait for that: the integration is created with `status = "pending_approval"` and Terraform prints a warning. Plerion doesn't scan the account until it is approved.

## New IAM roles

AWS can take a minute or two before it lets Plerion assume a role created in the same apply. The provider retries for up to two minutes.

## Deleting

`terraform destroy` removes the integration from Plerion. Plerion finishes the removal in the background, and the provider waits until it is gone.

## Schema

### Required

- `role_arn` (String) ARN of the IAM role Plerion assumes to read the account. The role must carry the tag `RolePurpose = PlerionAccess`. Pointing it at another AWS account replaces the integration.

### Optional

- `environment_id` (String) Plerion environment to put the account in. Left out, the integration keeps the environment it has, including one chosen in the Plerion console. Setting or changing it changes the environment's asset group, so the API key's role also needs `AssetGroup:Modify`.
- `instance_profile_arn` (String) Instance profile for workload scanning in the same account. Must be in the same account as `role_arn`, with no IAM path and only letters, digits, `-` and `_` in its name.
- `kms_key_access_mode` (String) Which KMS keys workload scanning may use: `ALL_KEYS` or `SELECTED_KEYS`.
- `name` (String) Display name. Defaults to the account alias, or the account id when it has none.
- `service_account_access_role_arn` (String) Role in this account that the service account assumes. Required with `service_account_id`.
- `service_account_id` (String) AWS account id of the service account that scans this account's workloads.
- `service_account_type` (String) Set to `PLERION_MANAGED` when Plerion runs the service account. Leave it out when you run your own. Changing it replaces the integration.

### Read-Only

- `account_id` (String) AWS account id, taken from `role_arn`.
- `id` (String) Integration id.
- `status` (String) `active`, or `pending_approval` while Plerion waits for someone to approve an account from an AWS organization the tenant hasn't seen before.

## Import

Import an integration by its ID, shown in the Plerion console. An account that is already connected to Plerion has to be imported before Terraform can manage it.

```shell
terraform import plerion_aws_integration.this <integration id>
```

An integration connected with a Plerion CloudFormation stack can be imported, but its stack still owns the role, workload scanning and KMS key access. Terraform can change its `name` and `environment_id`; anything else is refused until you update or delete the stack.
