# plerion_aws_service_account_region (Resource)

The network a service account's scanners run in, for one AWS region. Plerion checks through the service account's role that the VPC is tagged with your tenant id and that the subnet, security group and queue belong to it. Turning the region on and off stays in the Plerion console.

## Example usage

```terraform
resource "plerion_aws_service_account_region" "sydney" {
  account_id         = plerion_aws_service_account.this.account_id
  region             = "ap-southeast-2"
  vpc_id             = aws_vpc.plerion_appliance.id
  subnet_id          = aws_subnet.plerion_appliance.id
  security_group_id  = aws_security_group.plerion_appliance.id
  queue_url          = aws_sqs_queue.plerion_appliance_scan.url
  max_instance_limit = 10
}
```

## What Plerion checks

Before it saves the network, Plerion uses the service account's role to check that:

- the VPC carries a `PlerionTenantId` tag with your tenant ID,
- the subnet and the security group are in that VPC,
- the queue is a `plerion-appliance-scan-queue-*` queue in the same AWS account and region.

## Turning the region on and off

Turning the region on and off stays in the Plerion console, so `enabled` is read-only here. A new region starts on, and changing the network doesn't change it.

## Schema

### Required

- `account_id` (String) AWS account id of the service account.
- `queue_url` (String) URL of the scan queue in this account and region.
- `region` (String) AWS region, for example `ap-southeast-2`.
- `security_group_id` (String) Security group in that VPC.
- `subnet_id` (String) Subnet in that VPC.
- `vpc_id` (String) VPC the scanners run in. It must carry the `PlerionTenantId` tag.

### Optional

- `max_instance_limit` (Number) Most scanners that may run at once in this region, from 1 to 100. Defaults to 10.
- `template_version` (String) Version of the Plerion template this was made from, so Plerion can tell when it's out of date. The Plerion templates set it. Once set it is kept, even if you remove it from the configuration.

### Read-Only

- `enabled` (Boolean) Whether Plerion scans in this region. Turned on and off in the Plerion console.
- `id` (String) `<account_id>/<region>`.

## Import

Import a region by its AWS account ID and region, separated by a slash.

```shell
terraform import plerion_aws_service_account_region.sydney 123456789012/ap-southeast-2
```
