# plerion_custom_check (Data Source)

Looks up one custom check by its ID or its slug, including a summary of its latest run.

## Example usage

```terraform
data "plerion_custom_check" "github_oidc_roles" {
  slug = "github-oidc-roles-must-pin-a-repository"
}

output "github_oidc_roles_findings" {
  value = try(data.plerion_custom_check.github_oidc_roles.run_status.total_finding_count, null)
}
```

A slug lookup reads every check in the tenant, because the API has no filter for slugs. Look checks up by `id` when you have it.
